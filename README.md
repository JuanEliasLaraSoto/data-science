# credit-risk-lab

End-to-end credit risk modelling in the way a bank's risk function would do it:
an application **scorecard** (WoE + logistic regression), an **independent
validation report**, a **Monte Carlo portfolio model** (one-factor Vasicek) and a
**macro stress test** (ARIMAX on default rates).

> **Status:** Phase 1 (scorecard) is implemented and tested. Lending Club results
> are pending data access. The pipeline has been run end to end on the German
> Credit fallback dataset ([generated summary](reports/scorecard/german_credit/summary.md)).
> Every number in this repository is produced by a script in [`scripts/`](scripts/)
> and none is entered by hand.

## Reproduce

Requires [uv](https://docs.astral.sh/uv/) and Python 3.11+.

```bash
uv sync                                  # create the environment from uv.lock
export KAGGLE_USERNAME=... KAGGLE_KEY=...   # or ~/.kaggle/kaggle.json
uv run python scripts/download_data.py   # Lending Club + FRED -> data/raw/
uv run python scripts/run_scorecard.py   # Phase 1 -> reports/scorecard/lending_club/
make check                               # ruff + mypy --strict + pytest (coverage >= 85%)
```

## Methodological decisions

### Phase 1: scorecard

| Decision | Choice | Why |
|---|---|---|
| Target | `Charged Off`/`Default` = 1, `Fully Paid` = 0; unresolved loans dropped | Only resolved loans have a known outcome. The flag is a lifetime (36-month) default flag |
| Segment | 36-month, individual applications, current credit policy | One horizon and one population per scorecard. "Does not meet the credit policy" loans were underwritten under older rules |
| Sample windows | Development 2007–2014 (70/30 train/test, stratified by target and issue year), out-of-time 2015 | Every vintage has had 36 months to run off. Otherwise recent "resolved" loans would over-represent early defaults (maturity bias) |
| Leakage | Every post-origination field is dropped (payments, recoveries, `last_*`, hardship, settlement, funded amounts), with a reason per column in `data.LEAKAGE_COLUMNS` | The model may only use what was known at the decision |
| Other exclusions | Lending Club grade, sub-grade, rate and instalment; geography; free text; joint-application fields | Grade and rate are the incumbent model's output. Geography is a fair-lending proxy |
| Binning | Quantile fine classing, then pool-adjacent-violators to a strictly monotonic bad rate, minimum 5 % of observations per bin, at most 8 bins, missing values in their own bin when material | Monotonic, stable, explainable bins. Merging adjacent bins never breaks monotonicity |
| WoE convention | `ln(%good / %bad)`, so every logit coefficient must be negative | A positive coefficient contradicts the univariate evidence and signals multicollinearity |
| Selection | IV < 0.02 dropped. IV > 0.5 dropped unless a documented leakage review clears it. Pairwise \|ρ\| > 0.6 keeps the higher-IV variable. VIF > 5 removed iteratively. Backward elimination on sign and p > 0.05 | Standard industry thresholds. The IV ceiling triggers a review, it is not an automatic verdict |
| Scaling | 600 points at 50:1 good:bad odds, 20 points to double the odds | Points per bin add up to the score, which makes every decision explainable attribute by attribute |
| Challengers | Decision tree, random forest, gradient boosting on the same characteristics (raw values), tuned by 3-fold CV on train | They measure the cost of the scorecard's additivity and monotonicity constraints |
| Uncertainty | Gini 95 % CI from the DeLong variance; paired DeLong test for challenger vs scorecard | On small samples, Gini differences of several points can be pure noise |

## Limitations

- Lending Club results are pending access to the data in this environment. The
  German Credit run only exercises the pipeline: 1,000 loans, no dates and no
  out-of-time sample.
- Only accepted loans are observed and there is no reject inference, so the
  model describes the accepted population.
- The target is a lifetime (36-month) default flag, not a 12-month PD. Phase 3
  will need an explicit conversion to an annual PD.
