# credit-risk-lab

End-to-end credit risk modelling in the way a bank's risk function would do it:
an application **scorecard** (WoE + logistic regression), an **independent
validation report**, a **Monte Carlo portfolio model** (one-factor Vasicek) and a
**macro stress test** (ARIMAX on default rates).

> **Status:** Phase 0 (project setup). Results tables and figures will be added
> phase by phase. Every number in this README is produced by a script in
> [`scripts/`](scripts/) and none is entered by hand.

## Modules

| Module | Question it answers | Phase | Status |
|---|---|---|---|
| `data.py` | Where do the data come from, which fields are leaky, how is the out-of-time sample built? | 0–1 | Download ✅, cleaning ⏳ |
| `woe.py` | How is each variable binned, and how predictive is it (WoE / IV)? | 1 | ⏳ |
| `scorecard.py` | What is the PD model, and how does it map to points (base 600, PDO 20, 50:1)? | 1 | ⏳ |
| `benchmark.py` | How much performance does interpretability cost compared with tree ensembles? | 1 | ⏳ |
| `metrics.py` | How well does the model discriminate and calibrate (AUC, Gini, KS, Brier)? | 1 | ⏳ |
| `validation.py` | Would the model pass an independent validation (stability, calibration, concentration)? | 2 | ⏳ |
| `portfolio.py` | What are the portfolio's EL, VaR, ES and economic capital, and how do they compare with Basel IRB? | 3 | ⏳ |
| `stress.py` | How do default rates and losses move under a baseline and an adverse macro scenario? | 4 | ⏳ |

## Data

| Source | Use | Access |
|---|---|---|
| [Lending Club accepted loans 2007–2018Q4](https://www.kaggle.com/datasets/wordsforthewise/lending-club) | Scorecard, validation, portfolio, default-rate series | Kaggle API token |
| [FRED](https://fred.stlouisfed.org/): `UNRATE`, `A191RL1Q225SBEA` (real GDP growth), `FEDFUNDS` | Macro drivers for stress testing | Public CSV, no key |
| [German Credit (OpenML `credit-g`)](https://www.openml.org/d/31) | Fallback only. It has no dates, so there is no out-of-time sample | Public |

Raw and processed data are never committed. Only the download script is
versioned.

## Reproduce

Requires [uv](https://docs.astral.sh/uv/) and Python 3.11+.

```bash
uv sync                                  # create the environment from uv.lock
export KAGGLE_USERNAME=... KAGGLE_KEY=...   # or ~/.kaggle/kaggle.json
uv run python scripts/download_data.py   # Lending Club + FRED -> data/raw/
make check                               # ruff + mypy --strict + pytest (coverage >= 85%)
```

## Project structure

```
src/credit_risk_lab/   # all modelling logic (typed, tested)
scripts/               # entry points that produce every reported number and figure
notebooks/             # exploration and figures only; they import from src/
reports/               # figures and the validation report (PDF)
tests/                 # pytest suite
data/                  # raw/ and processed/ (git-ignored)
```
